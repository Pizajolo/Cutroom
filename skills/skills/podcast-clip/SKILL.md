# Podcast clip

**Format** 1080×1920 for socials (default) or 1920×1080 if the user wants it for YouTube. 30 fps.

**Finding the clip**
- Transcribe the full recording and read it end to end before choosing.
- Pick one moment that stands on its own: a story with an ending, a strong opinion, a counter-intuitive fact. If there are several good ones, make the best and offer the others.
- Start on the sentence that sets up the moment, not the question before it. End on the punchline, not the laughter after it.

**Cutting**
- Keep the conversation natural: trim only long pauses (> 0.6 s), false starts and tangents.
- If the frame is wide and the output is vertical, the centre crop must keep the speaker in frame — check frames, and tell the user if a speaker is cut off.

**Captions** Full-sentence captions, 1–2 lines, in the lower third; highlight the spoken word subtly. Readability over flash.

**Graphics**
- A headline bar at the top for the whole clip: 4–8 words that promise the payoff, written fresh (never clickbait the speaker didn't earn).
- Optional name tag for the speaker for the first 3 s if the user gave a name. Never guess names.

**Audio** Speech only. No music unless asked.

**Check before replying** Makes sense with zero context · starts and ends on complete sentences · headline is true to what is said.
