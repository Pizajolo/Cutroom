# Punch-in

- Split the clip at the start of the key line; on the second part set `crop` to the centre 80–88% (keep the eyes on the upper third). That is a cut-in, not an animated zoom.
- Hold for the length of the line (1–4 s), then return to the full frame at the next cut.
- At most one punch-in per ~8 s, and never two in a row at the same scale.
- Source must be sharp enough: skip it if the crop would drop below the output resolution by more than ~25%.
